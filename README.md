# Tahu Bulat for iOS (Native SwiftUI)

Game legendaris Tahu Bulat yang di-porting ke iOS secara native menggunakan **SwiftUI** dan **AVFoundation**.

## Fitur Native iOS:
- **100% Native SwiftUI**: Smooth 120Hz ProMotion animation di iPhone 13 Pro ke atas.
- **Haptic Feedback**: Getaran haptic taptic engine di setiap tap dan upgrade.
- **Combo & Multiplier System**: Tap cepat memicu mode combo hingga 3x lipat koin.
- **Pasar & 4 Kategori Upgrade**:
  - Dapur (Wajan, Kompor, Minyak)
  - Bumbu (Balado, Keju, Nori)
  - Promosi (Speaker Toa, Banner Neon, Jingle FYP)
  - Cabang (Pikap Grand Max, Stasiun, Mall)
- **Offline Earnings**: Koin tetap bertambah saat aplikasi ditutup/keluar.
- **Auto-build IPA**: Menggunakan GitHub Actions runner `macos-14` (Apple Silicon).

## Cara Install di iPhone:
Download file `TahuBulat.ipa` dari tab [Releases](../../releases) atau Artifacts GitHub Actions, lalu install menggunakan:
- **TrollStore** (Jailbreak / iOS CoreTrust exploit)
- **AltStore / Sideloadly** (Free Apple ID sideloading via PC/Mac)
- **Scarlet / Esign**
